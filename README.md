# VERDANT · 原野纪元

独立单人体素生存游戏，具有完整主线与通关后建造。不是 Minecraft 原版或完整移植。

## 在线游玩

[在 GitHub Pages 打开原野纪元](https://dreamxqwq.github.io/verdant-voxel-odyssey/)

无需登录、无需下载，使用电脑浏览器与键盘鼠标。每个人的存档分别保存在自己的浏览器中；这不是多人联机服务器。

## 自动部署

仓库的 GitHub Pages 使用 GitHub Actions 发布。每次推送到 `main` 会先检查语法与主线资源/存档测试，再发布 `dist/`。静态资源均为相对路径，适配 GitHub Pages 项目子目录。

如果复制此仓库，在仓库 Settings → Pages → Build and deployment 中将 Source 设为 GitHub Actions，然后运行 Deploy Verdant to GitHub Pages。无需部署密钥或第三方托管。

## 运行

在此目录运行 `node server.mjs`，浏览器打开 http://127.0.0.1:4173 。推荐桌面 Chrome / Edge，开启 WebGL 2 硬件加速。所有运行素材均打包在 dist，不依赖外部 CDN。

## 主线

1. 长按左键采集 6 个原木，采集 3 个原石。
2. E 打开背包，用 3 木 + 3 石合成石镐。
3. 采集 8 石合成熔炉。持石镐开采铁矿，消耗铁矿与木头熔炼至少 5 铁锭。
4. 3 铁 + 2 木合成铁剑。
5. 采集遗迹水晶，3 水晶 + 2 铁合成星门符印。
6. X 0 / Z -30 附近按 F 激活星门。
7. 躲避地面红色圆环，守卫俯冲时用铁剑攻击。击败守卫后出现结局，可返回原野继续建造。

露天矿：(-17,14)、(21,8)、(-27,-10)。水晶遗迹：(-24,3)、(24,-15)、(-20,-30)。

## 操作

WASD 移动；鼠标视角；空格跳跃/游泳；Shift 奔跑；左键采集/攻击；右键建造；数字 1–9/滚轮切换；E 背包合成；F 交互/食用；J 手册；R 安全返回；Esc 暂停。浏览器不支持锁定鼠标时，中键拖动可环顾。

## 范围

112 × 112 × 40 格可编辑世界；有限边界；单人本地存档与 JSON 导入导出；内置三种扩展及安全 JSON 参数包。无 MC 第三方模组运行时、多人联机、原版红石系统或无限世界。光影是实时软阴影、物理材质、顶点环境遮蔽、动态水面高光和远景雾，不是硬件光追。
